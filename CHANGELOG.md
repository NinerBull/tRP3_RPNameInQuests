### Note for Eavesdropper users
This update includes functionality that the awesome [Eavesdropper](https://github.com/Raenore/Eavesdropper) addon - which can also modify Quest text similarly to this addon - makes use of so that both addons won't both modify Quest Text and NPC Speech twice. Priority is given to this addon if Quest Text/NPC Speech modification is enabled, otherwise Eavesdropper will modify them instead. So please make sure both addons are up to date if you use both.
Thanks to Eavesdropper's Author, [Raenore](https://github.com/Raenore/) for the help!
